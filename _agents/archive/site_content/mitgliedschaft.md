# Mitglied werden

Alle immatrikulierte und ehemaligen Studierenden können Mitglied im Alumni Verein werden. Zur Finanzierung erheben wir von ehemaligen Studierenden eine Mitgliedsbeitrag von EUR 50,-. Dieser wird zum allergrößten Teil für die Unkosten, die im Rahmen von unseren Alumni Treffen entstehen verwendet.
